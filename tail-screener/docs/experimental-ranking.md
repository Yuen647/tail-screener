# HGB33 实验排序

本分发包提供实际模型重排。标准 `screen.py` 负责原候选资格、数据检查与原模拟账户；`rank_experimental.py` 只读其报告及完全相同的日线快照，给严格合格候选重新排序。不要将原流动性名单作为已完成的模型交付。

## 运行

正常筛选仍传入用户本次资金、最大仓位、展示数量和持有期，不从本模型复制案例参数。筛选完成后运行：

```bash
python scripts/rank_experimental.py --report 本次报告目录/report.json --output 新的实验报告目录
```

没有指定 `--top` 时沿用来源报告的展示数量；可以用 `--top 10` 仅改变展示数，不改变仓位或名义预算。`--snapshot 文件` 只用于快照搬迁后定位，内容哈希仍必须与来源报告相同。不要默读别的快照或联网重取。

脚本输出 `report.json`（完整模型顺序、展示名单、原流动性名次、分数、量价证据、来源哈希）及 `index.html`。返回 0 表示所有严格候选已完成模型评分，1 表示期限不适用或部分候选超出冻结特征范围，2 表示输入或模型校验失败。评分完成不表示市场背景全部完整；同时读取 `context_complete` 和缺项证券列表。

运行入口不改写来源报告、不写账户、不建立订单、不把原六只的公告核验转移给新六只。新名单展示为“实验研究候选”；若要进一步完成个股买入论证，重新逐只处理公告、行情时效及原交易约束，不因模型排第一省略步骤。

这里“不改账户”仅指只读重排入口。安装新包改变程序实现身份；以后运行正常扫描时沿用原版的账户隔离规则，不自动迁移或续写旧实现账户。不要为绕过身份检查而改哈希或重置旧账户。当前重排入口使用recent日线快照，archive报告未附同格式快照时明确返回缺少快照，不静默转换或重扫。

## 模型与范围

使用第06项研究 `ma_pool_ma_exit` 的固定 HGB：33项特征、150轮、最多7叶、学习率0.05、叶最少500样本、L2=10、随机种子1729。冻结模型训练信号为2016—2020，最后信号2020-12-15；它是已评估的2021折恢复，不是2026年新训练模型。

训练标签还包含最后信号之后的年内退出结果，因此只接受2021年及之后的信号，不把2020年12月16日误当作可使用日。

模型标签对应 H2。**H2只是该模型适用的预测标签，不是skill默认持有期。** 用户输入其他期限时，输出 `unsupported_horizon`，不改用户持有期、不把H2分数称为该期限预测；照常交付原期限基线报告及K线分析。没有适用模型不等于没有原规则候选。

历史测试名义单仓预算为4750元，入场涨幅上限3%、MA20溢价上限8%。运行预算仍由本次资金和最大仓位推导；不同预算或入场设置会明确标记 `tested_budget_and_entry_scope_matches=false`，不把旧收益移植为新设置的验证。冻结特征参考池保留8%溢价上限；用户放宽到8%以上时，超出部分保留为 `unscored`，不伪造分数。

市场背景特征使用所有上市年龄合格且20根日线完整的证券，百分位特征使用成交额、预算和8%上限合格的前MA池。最终可排名股票仍必须通过来源报告原严格资格与排除条件。若这些资格数量无法重现，停止模型重排并保留错误，不能缩池后伪称相同对照。

## 排名语义

按模型分数降序；同分按20日日均成交额、当日成交额降序，再按证券代码稳定排序。按请求展示前N只，不设置“预测必须为正”的新门槛，不为了买满仓位补充名单。模型分数沿用回归输出，但没有被验证为当前收益预测或胜率；展示数与持仓上限相互独立。

表内1日/5日涨跌、MA5变化和K线结构用于逐股解释观察证据，不是SHAP贡献或因果解释。不得把模型名次高直接写成趋势向上或未来必涨。

## 为什么保留这个方案

已有2019—2021三折向前研究中，原流动性平均净收益−0.4076%，HGB33为+0.0417%；剔除最高5笔后HGB33为−0.1387%，原晋级门槛未通过。新增40项K线模型为−0.2195%。因此保留HGB33作为用户请求的实验候选，并未宣称所有尝试中的通用最优或已验证盈利。

上述三折统计不是单个2021折模型的业绩，更不是本次当前名单的收益。模型恢复核对了2021年1386条原预测和231日顺序；JSON数值推理与sklearn预测一致。来源和原门槛结果见 `references/hgb33-validation.json`。未开启2024—2025收益、未重新搜索参数。
